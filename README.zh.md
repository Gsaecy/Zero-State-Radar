# dsh-cyberdeck — 末日工业 · 冷蓝控制台皮肤

一套纯前端皮肤插件：把 DSH 做成科幻 HUD 控制台。参考的是「深蓝底 + 青蓝霓虹细线 + 切角面板 + 技术读数」这一类界面，但只把风格放在**界面骨架**上，聊天正文区保持干净可读。

## 视觉语言

- **骨架**：侧边栏是钢板底 + 技术网格 + 细扫描线 + 底部积尘暖调；顶部 3px、底部 2px 黄黑警戒斜纹；一条冷青扫掠线从上往下慢慢走。
- **线条**：1px 青蓝细线 + 极淡外发光，输入区上沿中央一段亮线（像接口指示灯），代码块左侧 2px 警戒线。
- **窗口四角**：12px 的 L 形刻度，只在窗口最外缘 3px 处，不压任何按钮；顶部中央 190px 的刻度线、底部中央 96px 的短线。
- **切角**：新会话按钮是 45° 切角 + 四角短刻度；会话标题区加字距。
- 霓虹只在边框和刻度上，面板内部保持低对比，长时间看不累。

## 遮挡原则（重要）

- HUD 里**没有任何文字读数**，只有窗口最外缘的刻度线、左边缘刻度尺、顶部扫描线；全部 `pointer-events: none`。
- 侧边栏的网格 / 扫描线 / 警戒带都画在 `::before`、`::after` + `z-index: -1`，永远在会话列表文字下面。
- 浮层（下拉菜单、tooltip）是**独立 portal 层**，底由 `--dsw-menu-surface-fill` 决定；本皮肤把它换成深色半透明 + 青色细边，避免浅色底叠在深色界面上。

## 外观

- **只有一套：夜晚 · 废土控制室**。近黑蓝底（`#020610`）+ 霓虹青（`#35dcff`）+ 辉光，任何时候都长这样，不再跟随时间或 DSH 主题切换。
- 骨架：窗口四角 L 形刻度、侧边栏网格与扫描线、黄黑警戒带、输入区两端短刻度。

## 新对话的扫描线

空会话时，整个会话区背后有一条柔和的冷青光带**从上往下**走过（7.5 秒一轮），不画硬线：

1. 光带没到的地方什么都没有；
2. 光带经过的纬度，点阵世界地图随之显影（`clip-path` 从上往下揭开）；
3. 地图上随机浮出亮点 + 扩散光环，位置每次不同，像雷达回波；
4. 扫完之后地图与亮点再停留约 3 秒，淡出，下一轮重来。

线、地图、亮点都在 `.cyd-radar` 这一层里，`z-index: -1` + `isolation: isolate`，永远在标题与按钮下面，不抢点击。

尺寸不是写死的：`layoutRadar()` 找 hero 最近的 `*_scroll` 祖先（整个会话区），让雷达层**铺满这块区域**——从标签栏下方一直到窗口底部，宽度就是会话列宽，地图按区域拉伸填满。扫过输入框时被卡片挡住，只在背景里可见。窗口尺寸变化会重新量一次。

- 输入框里一有字，地图和扫描线立刻退场（`html[data-cyd-composing]`），不干扰阅读。
- 地图是内联的 `data:image/svg+xml` 点阵（1000×500 视口，4° 网格采样大陆多边形，约 1000 个点），没有外部资源。
- 想关掉：删掉第 8b 节，或把 `[class*="_hero"]` 那两个伪元素的 `animation` 去掉。

## 安装 / 卸载

- 安装（profile = desktop）：`dsh plugin --profile desktop add link:<本目录>`
- 也可用 DSH 设置里的插件管理安装本目录。
- 关掉皮肤（临时）：`Ctrl + Alt + K`，或控制台 `__cyberdeck.off()`；状态记在 `localStorage['dsh.cyberdeck.enabled']`。
- 彻底卸载：从 profile 依赖中移除 `dsh-cyberdeck` 并刷新页面。

## 想临时关掉皮肤

- `Ctrl + Alt + K`，或控制台 `__cyberdeck.off()`；状态记在 `localStorage['dsh.cyberdeck.enabled']`，刷新后保持。
- 想换主色：`__cyberdeck.setAccent('#22d3ee')`，或直接改第 0 节 `--cyd-accent`。

## 改哪里

打开 `lib/client.js`，CSS 按顺序分成：

1. **第 0 节 调参区**：`--cyd-*` 变量（底色、面板、描边、霓虹色、警戒色、网格、扫描线、辉光、刻度色、HUD 透明度）。
2. **第 1 节 调色板**：把 `--dsw-alias-*` token 换成冷蓝（应用浅色 / 深色主题共用同一组深蓝值，避免浅底上出现半深不浅的灰）。
3. **第 2 节**：全局细节（滚动条、选区、焦点环、代码块警戒线）。
4. **第 3 节**：侧边栏（钢板 + 网格 + 扫描线 + 积尘 + 警戒带 + 扫掠线 + 导航条 + 新会话切角）。
5. **第 4 节**：右侧窄栏。
6. **第 5 节**：主区（顶部冷光、输入区上沿亮线、会话头切角）。
7. **第 6 节**：HUD（窗口四角 L 刻度、顶部/底部中央刻度、左边缘刻度尺、顶部扫描线）。
8. **第 7 节**：深色主题收敛。
9. **第 8 节**：夜晚模式（霓虹调色板 + 输入框兜底深底）。
10. **第 9 节**：尊重 `prefers-reduced-motion`。

改完保存后刷新页面（⌘R）即可生效。profile 里的副本与工作区文件是**同一个 inode**（就地改写会同步），如果用「先删后写」的方式保存就会断开，需要重新安装。

## 选择器约定

DSH 的组件类名是 CSS Modules，带随版本变化的哈希前缀（例如 `PIRFFq_sidebarCol`）。本插件统一用 `[class*="_sidebarCol"]` 这类**子串匹配**，所以升级 DSH 后不会因为哈希前缀变化而失效。若某个模块改了类名（如 `_composerSeat`），把对应选择器换成新的类名子串即可。

## 已知边界

- 只覆盖深色 / 浅色两套内置主题，第三方主题的 token 可能被本插件覆盖。
- `color-mix()` 需要 Chromium 111+；DSH 桌面版满足，若在很旧的浏览器里打开，个别渐变的透明度会失效（不影响布局）。
- HUD 用 `position: fixed; z-index: 40`；如果以后往 HUD 里加东西，先确认它落在窗口边缘 8px 以内，别压到头部按钮或底部状态栏。
- 自动切换用本地时间判断，跨零点的时间段（如 22:00–07:00）按「大于起点或小于终点」处理；改系统时区后以新时区为准。

## 空态不画输入框边框

新对话、还没输入内容时，输入框自己**不画边框、不加描边**（只剩一层很淡的底色），所以不会有一条横线横在标题下面；一开始打字（`html[data-cyd-composing]`）边框立刻回来。

```css
html[data-cyberdeck]:not([data-cyd-composing]) [class*="_composerSeat"] [class*="_card"] {
  border-color: transparent !important;
  box-shadow: none !important;
}
```


## 左下角数据监控

空态背景的左下角有一块 `SYS // TELEMETRY` 读数：

- `SCAN`：当前扫描周期内的秒数（0–9s）
- `SIG`：一个按正弦波 + 微抖动的信号强度（0.12–1.00），模拟信号起伏
- `NODES`：网络层里城市节点的实际数量（从 DOM 里数）
- 每条读数右侧有一根**横向进度条**（`SCAN` 按周期进度、`SIG`/`LOAD` 按数值、`NODES` 按 60 个上限），宽度用 `transition: width .35s ease` 平滑推进

数值由 `updateMonitor(layer)` 更新，随 `spawnPing` 的 1.1 秒节拍刷新；样式在 `.cyd-monitor`，位置用 `left: 18px; bottom: 14px` 控制。

**出场时序**：扫描线第一次扫到左下角（约 4.0s，常量 `MONITOR_AT = RADAR_CYCLE * 0.44`）之前保持隐藏；扫过时先播 0.5 秒**信号干扰**（`cyd-mon-glitch`：横向抖动 + `clip-path` 切片 + 亮度/色相闪），再 0.6 秒渐显到 92%。

**之后一直显示**，不再随扫描周期隐藏，直到离开空态（有对话消息，`.cyd-radar` 整层被移除）才随之消失。显示期间每隔 2.6–6.8 秒随机再抖一次（`is-glitch`，0.43 秒）。没有边框和底色，只有文字、横条和数值。

**干扰是按行做的**，不是整块：`cyd-row-glitch` 加在 `.cyd-mon-hd` 与每个 `.cyd-mon-row` 上，每行有自己的 `--gx` 幅度（0.9–2px）和 0.06s 递进的延迟，横条本体另有 `cyd-row-bar` 做亮度/色相闪。所以看起来是「数据在跳」，而不是一张图被整体抖动。


## 什么时候出现、什么时候消失

扫描 + 地图 + 监控只在**空会话**（等第一条消息）时出现。判定与退出有三重保险：

1. 找不到 hero（`[class*="_hero"]`）→ 直接移除；
2. DOM 里出现消息节点（`_messageRow` / `_msgRow` / `_chatMessage` / `_bubble` / `_turnBody` / `_assistantText` 等）→ 移除；
3. 在输入框里按 **Enter 发送**（不按 Shift）→ 立即移除。

所以发出第一条消息的瞬间，特效就没了，不需要等下一轮 1.1 秒的检查。
